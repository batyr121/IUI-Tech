# IUI Technology — AI NeuroLearning Platform

Full-stack SaaS-платформа для образовательной EEG-аналитики. Приложение включает PostgreSQL, Prisma, защищённую авторизацию, публичный лендинг и отдельные кабинеты учителя, ученика и родителя.

## Возможности

- Адаптивный лендинг в светлой premium-теме
- Авторизация для учителя, ученика и родителя
- Регистрация ученика и родителя по invite-коду
- Dashboard с реальными когнитивными метриками, XP, Level, Streak и достижениями
- Конфетти за реальные достижения, недельные цели и календарь регулярности
- Самостоятельная регистрация ученика по коду класса
- Управление классами, архивом и профилями учеников
- Персональное приглашение родителя к одному ученику
- Единое Bluetooth LE-подключение, handshake, Device ID, firmware, heartbeat и калибровка ESP32 / BioAmp EXG
- Проверка совместимости и уведомления о версиях прошивки; обновление выполняет команда IUI
- Live EEG-сессия с целью по времени и анимированными графиками
- Пауза/продолжение, focus mode, отсчёт перед записью и milestone-анимация
- AI-аналитика внимания, фокуса, вовлечённости, усталости и стабильности
- Детальные PDF, Excel и CSV-отчёты
- Обязательная первая диагностика знаний + EEG для 1–11 классов на русском или казахском языке
- Автоматический 7-дневный маршрут после диагностики: 3–5 микро-заданий в день в зависимости от класса
- Контрольная диагностика в середине недели: 6 новых заданий + EEG, сравнение знаний, внимания, фокуса, вовлечённости, усталости и расслабления
- Автоматическая адаптация только будущих заданий после контрольной точки; уже выполненный прогресс не меняется
- Недельный B2C-цикл: диагностика → домашняя практика → учебный отчёт → повторная диагностика
- Учебный отчёт для родителя и преподавателя с пробелами, точностью, регулярностью и следующими шагами
- Центр событий, настройки профиля и безопасная смена пароля
- Ролевая JSON-выгрузка данных аккаунта и production readiness-проверка PostgreSQL

## Локальный запуск

Требуются Node.js 20 или новее и PostgreSQL 15+ (локальный либо облачный Neon/Supabase/Railway).

```bash
npm install
cp .env.example .env
npm run db:generate
npm run db:push
npm run dev
```

Перед `db:push` заполните `DATABASE_URL` и задайте длинный случайный `JWT_SECRET` в `.env`. Frontend откроется на `http://localhost:5173`, API — на `http://localhost:3001`.

## Production-сборка

```bash
npm run build
npm run audit
npm run preview
```

Frontend появится в `dist`, сервер — в `server-dist`. В production Node-сервер раздаёт оба слоя одной командой `npm start`.

## Деплой

Это full-stack приложение с постоянным Node.js-процессом, Socket.IO и PostgreSQL. Для размещения всей платформы используйте Railway, Render, Fly.io либо обычный VPS.

1. Загрузите репозиторий на GitHub.
2. Создайте Node.js Web Service.
3. Build Command: `npm ci && npm run build`.
4. Start Command: `npm start`.
5. Добавьте `DATABASE_URL`, `DIRECT_URL`, `JWT_SECRET` (не короче 32 символов), `CLIENT_URL`, `NODE_ENV=production` и `TZ=Asia/Aqtau`.
6. Укажите HTTPS-адрес сервиса в `CLIENT_URL` без пути и завершающего `/`.
7. До первого запуска выполните `npm run db:push` для создания таблиц диагностики, недельных планов и попыток заданий.

Для проверки контейнера используйте `/api/health`, а для проверки готовности приложения вместе с PostgreSQL — `/api/ready`. Конфигурации Railway и Render уже используют readiness-маршрут.

Vercel и Netlify можно использовать только для отдельного статического frontend. В таком варианте Express API и Socket.IO необходимо разворачивать отдельно и настраивать внешний API URL. Простая публикация папки `dist` не создаёт backend и не обеспечивает сохранение данных.

## Backend и безопасность

- Пароли хешируются bcrypt с cost factor 12.
- Сессия подписывается JWT и хранится в `HttpOnly`, `SameSite=Lax`, `Secure` cookie.
- Все запросы проверяют организацию и роль пользователя.
- EEG отправляется пакетами до 1000 отсчётов и сохраняется в PostgreSQL.
- Socket.IO готов для трансляции активной сессии наблюдателям.
- Для production включите HTTPS, резервные копии PostgreSQL и отдельный секрет в панели хостинга.

### Формат потока ESP32

Устройство должно отправлять одну JSON-запись на строку:

```json
{"raw":512,"attention":84,"meditation":72,"engagement":81,"focus":88,"relaxation":69,"blink":0,"signal":96}
```

Частота может быть любой разумной; frontend группирует данные для серверной записи.

## Bluetooth LE

Пользовательское подключение работает только через Web Bluetooth в Chromium-браузерах (Chrome/Edge) и требует HTTPS на хостинге либо localhost при разработке. После первого выбора устройство переиспользуется в разделах «Устройства», «Диагностика» и «Live EEG» без повторного системного окна. USB нужен только для загрузки прошивки командой IUI и не используется в интерфейсе ученика.

## Проверка B2C-контура

Команда `npm run audit` выполняет production-сборку и автоматически проверяет уникальность API-маршрутов, модели Prisma, обязательность EEG, Bluetooth-only транспорт, отсутствие демо-значений в production-бандле, все 22 варианта первой и контрольной диагностики и все 22 варианта недельных планов. Для каждого задания дополнительно проверяются четыре уникальных ответа, подсказка и объяснение.

При запущенном `npm run dev` для отдельной проверки настоящего маршрута через API и Supabase запустите `npm run test:checkin`. Скрипт создаёт изолированный временный профиль, проверяет сохранение нейродинамики, адаптацию и идемпотентный повтор запроса, затем удаляет все тестовые данные.

### Контрольная точка недели

Контрольная диагностика открывается после двух полностью выполненных учебных дней либо на четвёртый день маршрута. Ребёнок отвечает на шесть новых вопросов своего класса одновременно с EEG-записью. Платформа сохраняет общий и предметные результаты, дельты внимания, фокуса, вовлечённости, усталости и расслабления, а также качество сигнала. После сохранения изменяются только ещё не открытые и не выполненные задания; история ответов, XP и завершённые задания остаются неизменными. Один недельный план может иметь только одну контрольную точку, а повтор сетевого запроса возвращает уже сохранённый результат.
