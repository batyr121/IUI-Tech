# IUI NeuroBand — ESP32 + BioAmp EXG Pill

## Подключение

| BioAmp EXG Pill | ESP32 DevKit |
|---|---|
| VCC | 3V3 |
| GND | GND |
| OUT | GPIO34 |

Используйте питание от аккумулятора или USB-ноутбука. Не используйте сомнительные сетевые блоки питания во время подключения электродов к человеку.

## Загрузка

1. Установите Arduino IDE и пакет плат `esp32 by Espressif Systems`.
2. Выберите `ESP32 Dev Module`.
3. Откройте `iui_bioamp_esp32.ino`.
4. Выберите COM-порт и нажмите Upload.
5. В Serial Monitor установите `115200 baud` и `Newline`.

После запуска плата отправляет handshake с уникальным ID, сформированным из eFuse MAC. Поток остаётся остановленным, пока платформа не выполнит калибровку и не отправит `START`. Текущая версия протокола — `1.1.0`.

## Команды

- `INFO` — повторить handshake;
- `START` — начать передачу;
- `STOP` — остановить передачу;
- `CALIBRATE` — трёхсекундная калибровка в спокойном состоянии;
- `PING` — проверка связи.

ADC снимается с частотой 250 Hz, но агрегированная JSON-телеметрия отправляется 10 раз в секунду, чтобы не переполнять Serial 115200.

Показатели attention/meditation/focus являются прозрачными эвристическими UI-индикаторами. Для научно обоснованной оценки необходимо валидировать алгоритм на размеченных данных и рассчитывать спектральные мощности EEG.
